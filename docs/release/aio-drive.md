# AIO Drive

Release assets include:

- macOS Finder installer as `.dmg`
- macOS `aio` CLI archive
- Linux `aio` CLI archive
- Windows `aio` CLI archive

Current platform scope:

- macOS: Finder integration + CLI
- Linux: CLI / daemon
- Windows: CLI / daemon

Finder / Explorer / Nautilus shell integration is only implemented for macOS in this release.
